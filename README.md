# Studying-Python-001
Este programa simples em Python é sobre um portão de acesso com duas variáveis, um inteiro e um booleano, com uma estrutura condicional que verifica se o nível de acesso é maior ou igual a cinco. Se for, ele muda a variável do portão desbloqueado para mostrar que está aberto. Caso contrário, o acesso é negado.
